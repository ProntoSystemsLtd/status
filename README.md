Public status page for Pronto Systems services, built with [Upptime](https://upptime.js.org).
Checks run every 5 minutes from GitHub Actions; uptime and response-time history is committed
to this repo; incidents are GitHub Issues.

## Maintenance

- **Add or change a component:** edit `sites:` in `.upptimerc.yml`, commit, push. Setup CI rebuilds the page.
- **Post an incident:** open an Issue in this repo with the `status` label plus the component's slug
  as a label (e.g. `api`); comments become updates; close the Issue to resolve it.
- **Outages are detected automatically:** Upptime opens an Issue when a check fails and closes it on recovery.

Do not list internal, UAT or monitoring hosts here — this repo and page are public.
